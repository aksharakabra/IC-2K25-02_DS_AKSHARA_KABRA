<i> A Queue is the organisation of data items in majorly FIFO manner, where elements are inserted in one end known as REAR (tail) and removed from another end called FRONT (head).<br>
<b> QUEUE is therefore used to store data that needs to be processed in the order of its arrival.<br>
<h2>Kendall's notation</h2><br>
A/S/c/K/N/D<br>
arrival distribution/service time distribution/number of server/capacity of queue/size of calling population/queueing pattern(LIFO, FIFO)<br>
