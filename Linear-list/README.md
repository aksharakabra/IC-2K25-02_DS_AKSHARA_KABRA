<h2>LIST</h2>
<b>A list is a collection of elements arranged in a particular sequence.</b><br>
<h2>LINEAR LIST</h2>
<B>A linear list is a list in which elements are arranged sequentially, one after another.<br>
it can have no items or duplicate items<br>
A Linear List is an ADT<br>
An array can be used to implement a list, but:
Array and List are not exactly the same concept.</B>
<h3>example</h3>
<pre>Student 1 → Student 2 → Student 3 → Student 4 → Student 5</pre>
we can represent linear list as:
<pre>L = (a₁, a₂, a₃, ..., aₙ)<hr>
where:
<ul>
<li>L = the list</li>
<li> a₁ = first element</li>
<li> a₂ = second element</li>
<li> a₃ = third element</li>
<li> aₙ = last element</li>
<li> n = number of elements</li>
</ul>
</pre>
<h2>EMPTY LINEAR LIST</h2>
<b>A list doesn't necessarily have to contain elements.</b>
<pre>L = ( )
the size is 0</pre>
<h2>SINGLETON LINEAR LIST</h2>
<b>It has only one element</b>
<pre>L = (25)
the size is 1</pre>
